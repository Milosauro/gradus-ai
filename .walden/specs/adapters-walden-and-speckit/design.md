# Feature Design

## Architecture

This feature introduces a declarative adapter registry and CLI (`gradusctl adapter`) built strictly on Go stdlib and existing Gradus packages:

1. **Embedded Official Adapters (`adapters/embed.go`, `adapters/walden/adapter.yaml`, `adapters/spec-kit/adapter.yaml`):**
   - `adapters/embed.go` exports `//go:embed */adapter.yaml` `var FS embed.FS`.
   - `adapters/walden/adapter.yaml`:
     - `schema: gradus/v1`, `id: walden`, `name: Walden`, `target_file: .walden/constitution.md`, `version_command: ["walden", "version"]`, `evidence_command: ["walden", "release", "check", "--json"]`.
   - `adapters/spec-kit/adapter.yaml`:
     - `schema: gradus/v1`, `id: spec-kit`, `name: Spec Kit`, `target_file: .specify/memory/constitution.md`, `version_command: ["specify", "--version"]`.

2. **Adapter Engine (`internal/adapter/`):**
   - `Manifest` struct: `Schema`, `ID`, `Name`, `Description`, `TargetFile`, `VersionCommand []string`, `EvidenceCommand []string`, `Source string` (`official` | `custom`, `yaml:"-"`).
   - `LoadRegistry(rootDir string, officialFS fs.FS) (map[string]Manifest, error)`:
     - Parses all `*/adapter.yaml` from `officialFS` (`Source: "official"`).
     - Scans `.gradus/adapters/*.yaml` and `.gradus/adapters/*/adapter.yaml` (if present) (`Source: "custom"`), allowing project-local custom adapters or overrides.
     - Validates `schema == "gradus/v1"`, non-empty `id` (`^[a-z][a-z0-9-]*$`), non-empty `target_file`, and strict relative path containment (rejects `filepath.IsAbs`, `..` segments, or paths resolving outside `rootDir`, satisfying `R1.AC3` / `NFR2`).
   - `RenderConstitution(existing string, view resolve.ResolvedView) []byte`:
     - Reuses `compile.PlanAgentsMD(existing, view)` (which renders `RenderPrecedenceHeader` + all active non-user rules inside `<!-- gradus:begin view_hash=... --> ... <!-- gradus:end -->` via `ApplyManagedSection`), guaranteeing byte-for-byte preservation of surrounding prose and zero-diff idempotency (`R2.AC1`, `NFR3`).
   - `Sync(rootDir string, m Manifest, view resolve.ResolvedView) (SyncResult, error)`:
     - Reads existing `target_file` (optional), renders content, and writes via `compile.WriteIfChanged`.
   - `Verify(rootDir string, m Manifest, view resolve.ResolvedView, requires map[string]string, skipEvidence bool) VerifyResult`:
     - **Drift check:** compares on-disk bytes of `target_file` against `RenderConstitution(existing, view)` (missing file -> `missing`; differing bytes -> `drift`).
     - **Version check:** if `requires["cli"]` is non-empty and `len(m.VersionCommand) > 0`, runs `m.VersionCommand` via `os/exec` (argv array, no shell), extracts the first SemVer token (`v?\d+\.\d+\.\d+(?:-[0-9A-Za-z.-]+)?`), and checks against `requires["cli"]` supporting `>=`, `>`, `<=`, `<`, `==`, `=` (default `>=` if bare version) via `schema.ParseSemVer` / `CompareSemVer`.
     - **Evidence check:** if `!skipEvidence && len(m.EvidenceCommand) > 0`, runs `m.EvidenceCommand` via `os/exec` in `rootDir`; non-zero exit records an evidence failure.

3. **CLI (`internal/cli/adapter.go`, `internal/cli/root.go`):**
   - `gradusctl adapter list [--dir .] [--json]` (`R3.AC1`)
   - `gradusctl adapter sync [--dir .] [--provider <id>] [--json]` (`R2.AC1`, `R2.AC4`)
   - `gradusctl adapter verify [--dir .] [--provider <id>] [--skip-evidence] [--json]` (`R2.AC2`, `R2.AC3`, `R2.AC4`)
   - Exit codes: `0` pass, `1` verify failure (drift / version mismatch / evidence failure), `2` invalid manifest, unknown provider, or config/resolve error.

## Options Considered

- **Chosen:** Declarative YAML manifests (`adapters/*/adapter.yaml` + `.gradus/adapters/`) executed via `os/exec` argv arrays, reusing `compile.PlanAgentsMD` for managed-section rendering.
  - Matches §19 ("custom ones are declarative manifests generated by `gradus-link`"), keeps official and custom adapters on one uniform code path, and avoids shell injection.
- **Alternative:** Hard-code Go structs for `walden` and `spec-kit` with custom Go code per provider.
  - Rejected: forces custom providers to wait for binary releases and prevents `F19` (`gradus-link`) from generating declarative manifests.

## Simplicity And Elegance Review

- Reusing `compile.PlanAgentsMD` avoids duplicating managed-section rendering logic while keeping `AGENTS.md` and provider constitution sections format-consistent.
- Executing `version_command` and `evidence_command` strictly as argv slices (`exec.Command(argv[0], argv[1:]...)`) prevents command injection and works identically across macOS, Linux, and Windows.

## Failure Modes And Tradeoffs

- **Provider CLI not installed on developer machine:** `verify` reports a clear version/evidence check failure (exit `1`) when `requires.cli` or `evidence_command` cannot execute, and `--skip-evidence` allows fast offline constitution-drift-only verification when needed.
- **No bound providers:** `adapter sync` and `adapter verify` with no `--provider` flag and zero bindings in `ResolvedView` return `0` with an empty result list rather than failing on repos that do not use obligations yet (`C2`).

## Verification Plan

- Unit tests in `internal/adapter/adapter_test.go` covering embedded official manifests (`walden`, `spec-kit`), custom `.gradus/adapters/` loading, path-traversal rejection (`../outside.md`), managed-section sync preservation + idempotency, drift detection, SemVer constraint checking (`>=`, `<`, invalid), and mock command evidence pass/fail (`R1.AC1`–`R1.AC3`, `R2.AC1`–`R2.AC3`, `NFR1`–`NFR3`).
- CLI tests in `internal/cli/adapter_test.go` exercising `gradusctl adapter list`, `adapter sync`, `adapter verify` (pass, drift fail exit 1, unknown provider exit 2), and `CGO_ENABLED=0` static build (`R2.AC1`–`R2.AC4`, `R3.AC1`, `C1`, `C2`).
