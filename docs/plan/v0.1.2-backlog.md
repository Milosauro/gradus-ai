# Technical Debt & Hardening Backlog (`v0.1.2`)

Items identified during the `v0.1.1` external security and quality review, deferred until after real-world field testing (`O-1` and live `E9`) so real usage findings can be bundled into the next hardening release.

## High / Medium-High Priority

- [ ] **Anti-tamper coverage gaps (Threat Model T2):**
  - Protect `.claude/settings.local.json`, `.git/hooks/**`, and `.githooks/**` in `internal/guard/antitamper.go`.
  - Detect mutating shell bypasses in `IsProtectedShellCommand`:
    - `git config core.hooksPath ...`
    - `git checkout <old-ref> -- .gradus` (and `git restore` / `git reset` on governance paths)
    - Redirections without whitespace (e.g., `echo x>gradus.yaml`)
    - `find ... -delete`, `ln -sf`, `unlink`, and shell globs (`rm gradus.y*`)
  - Clarify in `README.md` FAQ that in-session anti-tamper is defense-in-depth, while CI (`gradusctl verify` / `check`) is the hard guarantee.

## Medium Priority

- [ ] **Lesson redaction gaps & false positives (`internal/state/redact.go`, Threat Model T4):**
  - Add redaction patterns for PEM private keys (`-----BEGIN ... PRIVATE KEY-----`), Italian fiscal codes (Codice Fiscale), and mobile phone numbers with contiguous 7-digit suffixes (e.g., `+39 333 1234567`).
  - Tighten phone number regex to eliminate false positives on generic space-separated number sequences.

## Medium-Low / Minor Priority

- [ ] **Git ref option-injection hardening (`internal/source/git.go`):**
  - Reject git refs starting with `-` (e.g., `--orphan=evil`) before passing them to `git checkout`.
